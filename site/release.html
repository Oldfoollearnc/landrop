V1.0.0 内测版

首个面向内部试用的完整版本：把设备控制、局域网远控、授权审计与团队协作集中到一个 Windows 工作台。

发布日期
2026-11-17
平台
Windows 10 / 11 x64
渠道
内部内测
分发方式
内部 IT 分发

版本概览

V1.0.0 是近传 · 远程工位的第一个内部内测版本，面向同一局域网内的 Windows 办公电脑。控制端与被控端通过 P2P 直连，不经过云端；设备授权、临时权限与审计记录留在工位端。

本次发布覆盖从配对、连接到控制、文件与协作的完整流程，并保留了明确的边界：仅限同一 Wi-Fi 或 VLAN，不提供公网穿透与集中管理。

内测说明：版本仍在内部试用阶段。请通过内部 IT 获取安装包，不要对外分发或用于生产环境的无人值守场景。

新增功能

10 项

首个内测版包含以下能力，覆盖设备管理、远程会话、授权与协作。

统一工作台设备、会话、授权、审计、诊断与设置集中在同一窗口。
真实局域网屏幕与键鼠传输真实桌面与输入，支持常用快捷键和剪贴板。
6 位码配对被控端生成配对码，控制端输入后在工位端确认连接。
本机被控每台电脑都能作为被控端，连接请求与本机权限可见。
团队群聊入口从工作台进入团队群聊，集中处理讨论与支持请求。
同事私聊与同事一对一沟通，不离开当前工作台。
设备详情在线状态、网络、显示器、最近会话与权限集中展示。
授权 / 审计 / 诊断 / 设置临时授权、到期提醒、连接记录与网络自检。
浅色 / 深色控制台支持两套外观，按使用场景切换。
本机被控与授权6 位码配对、授权列表、录制状态与随时撤销；管理员临时支持默认 8 小时。

已知限制

内测阶段

以下限制已在版本中确认，会在后续内测版中逐步处理。请在试用前与内部 IT 对齐使用边界。

仅限同一局域网 不提供公网穿透、跨网段访问或关机唤醒；控制端与被控端需处于同一 Wi-Fi 或 VLAN。
JPEG 传输层 当前屏幕帧由 Windows GDI 采集并经局域网 WS + JPEG 传输：1080p 约 15fps、2K 约 10–12fps、720p 约 20fps；后续计划切换至 WebRTC。
局域网 WS 通道 当前控制通道是本机内网 WS，未启用跨网 TLS/证书固定；只允许在受控的办公 VLAN 内使用，不要暴露到公网。
锁屏 / UAC 安全桌面 锁屏与 UAC 安全桌面需要原生服务配合，当前版本不能保证在所有机型上完成此类操作。
文件传输范围 控制端可发送到被控端；被控端会话中也可“发送文件给控制端”。完整的远程文件浏览器尚未开放。
无 Hub / 无集中管理 不设中心服务器，设备、授权与审计数据分布在各工位电脑，不支持组织级集中管理。
管理员授权默认 8 小时 临时管理员授权默认 8 小时到期；无人值守模式默认关闭，需要在工位端明确开启。
会话录制 录制默认关闭；当前由控制端在本地录制 WebM，尚未接入服务端保留策略、录制审计与员工拒绝流程。

升级与回滚

内测版本通过离线安装包更新。升级与回滚都应在内部 IT 的指导下进行，并避开正在进行的远程会话。

升级到 V1.0.0
  1. 结束当前会话确认没有正在进行的远程会话或文件传输。
  2. 覆盖安装从内部 IT 获取安装包，退出近传后覆盖安装。
  3. 核对状态启动后核对版本号，并确认设备授权与审计记录可见。
回滚到上一内测版
  1. 记录当前状态如需保留审计信息，先联系内部 IT 记录当前状态。
  2. 安装旧版卸载 V1.0.0，再安装上一版内测安装包。
  3. 重新确认授权检查设备配对与授权关系；失效时在工位端重新生成授权。
兼容性提示：内测版本不保证配置与审计数据向下兼容。执行回滚前，请先与内部 IT 确认影响范围。

系统要求

控制端与被控端都运行 Windows 桌面版，并通过同一局域网互通。

操作系统Windows 10 / 11 x64
网络同一 Wi-Fi 或 VLAN，局域网互通；不依赖公网连接
无线建议 5GHz；2.4GHz 可用于轻量操作
画面支持 1080p 至 2K，双屏可切换
安装与更新内测安装包与离线更新包，由内部 IT 分发
账号使用本机 Windows 账户，不新建产品账号
锁屏 / 安全桌面内测版暂不支持；需要原生 Windows 服务。PIN、指纹与面容不用于远程输入

反馈方式

内测期间的安装、授权与兼容性问题，请通过内部 IT 服务台反馈。

提交反馈时请附上

版本号 V1.0.0、设备名称、问题发生的操作步骤，以及诊断页中的网络与会话信息。

请勿在反馈中发送 Windows 密码、PIN 或包含敏感信息的完整屏幕截图；如涉及敏感画面，只描述问题并附诊断编号。
