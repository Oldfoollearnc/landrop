# 近传 · 远程工位 — 网站介绍页

“近传 · 远程工位 3.0.0”内部内测版的静态介绍页与发布说明页。纯 HTML + CSS，无外部字体、无 CDN、无 JavaScript 依赖。

## 打开方式

直接双击 `site/index.html` 即可在浏览器中打开，页面之间使用相对路径跳转。

也可以启动一个本地静态服务（图片和锚点行为一致）：

```bash
cd site
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。不需要安装依赖，也没有构建步骤。

## 图片说明

- 图片均为 Windows 桌面端界面截图，尺寸 `1800 × 1245`，已复制到 `site/img/`，页面全部使用相对路径引用。
- 截图中的姓名、部门、设备编号与连接信息均为界面演示数据，不代表真实人员或资产。
- 替换图片时请保留原文件名，或同时修改对应 HTML 中的 `src`、`width` 与 `height` 属性。
- 页面未引用任何外部图片或网络资源，离线打开也能完整显示。

## 内容维护

- 版本号、发布日期出现在 `index.html` 的下载区，以及 `release.html` 的页头与侧栏；发版时需要同步修改。
- 下载按钮已指向 GitHub Release `v3.0.0` 的 Setup 安装包；发布页与 `SHA256SUMS.txt` 同版本。内测包也可由内部 IT 分发。
- 顶栏锚点：`#features`、`#security`、`#chat`、`#deploy`、`#download`；发布页使用 `index.html#…` 跨页跳转。
- 如调整导航项，请同步修改 `index.html`、`release.html` 与两个页脚中的链接。

## 设计约束

- 浅色主题：冷灰背景 `#F5F7FA`、白色表面、细边框；近传蓝 `#2563EB` 为唯一主色。
- 字体仅使用 `"Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", system-ui, sans-serif`，不加载在线字体。
- 圆角 6–10px，卡片使用 1px 边框与极轻阴影；不使用渐变堆叠、玻璃拟态或聊天气泡装饰。
- 响应式布局在 1280 / 1024 宽度下完整可用；窄屏下导航自动换行，不依赖 JS 菜单。
- 所有页面信息均为静态内容；页面无统计脚本、无第三方请求。

## 适用说明

本页面用于内部介绍与内测分发说明，不构成商业授权或对外销售材料。产品仅面向同一局域网内的 Windows 10 / 11 x64 设备，不提供公网远程、关机唤醒或移动端控制能力。
