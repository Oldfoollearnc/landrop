# 近传 · 局域网群聊设计与实现

> 目标：把原来的「手机 ⇄ 一台电脑」单会话，升级为「一台电脑做群主，手机和其他电脑扫码入群」的局域网群聊。群聊不依赖外网、不需要账号；除群主电脑外，任何设备都能用浏览器直接加入。

## 一、核心决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 群的数量 | 单群 | 群主电脑就是房间；扫码即入。多群是另一个产品复杂度 |
| 群主 | 运行 NearSend 的电脑 | 已有 HTTP + WebSocket 服务、文件落盘、二维码、托盘常驻 |
| 群成员 | 群主 + 所有加入的设备 | 群主参与聊天；旧聊天记录自然成为群历史 |
| 其他电脑 | 浏览器网页版 | 不装 App；宽屏自动切换成桌面双栏布局 |
| 手机 | 网页版 / Android App | 沿用现有能力，补成员、@、群系统消息 |
| 身份 | 设备本地保存 memberId + key | 首次入群填昵称、选头像色；重连保持身份 |
| 消息真源 | 群主电脑 | 与现有隐私模型一致：记录只在电脑上，且加密落盘 |
| 私聊 | 不做 | 单群已覆盖「自己设备之间传东西」；避免双模式分裂 |
| 入群凭证 | 现有访问令牌（二维码/链接） | 复用已有鉴权、PWA、Android 配对 |

## 二、角色与权限

| 能力 | 群主（电脑） | 成员 |
|---|---|---|
| 收发文字/图片/文件 | ✓ | ✓ |
| 引用、撤回自己的消息、删除自己的消息 | ✓ | ✓ |
| 删除任意消息 | ✓ | — |
| 查看成员/在线状态/邀请二维码 | ✓ | ✓ |
| 修改群名、自己的昵称 | ✓ | 只能改自己的昵称 |
| 锁定群聊（禁止新成员） | ✓ | — |
| 移出成员 / 恢复成员 | ✓ | — |
| 重置邀请链接 | ✓ | — |
| 清空群聊记录 | ✓ | — |
| 退出群聊 | —（群主即房间） | ✓ |

安全边界：入群令牌是邀请凭证（同一局域网、拿到链接即可入群）；成员 key 用于防止普通冒名发消息，浏览器请求必须带 key，旧版 Android 原生兼容通道除外；这不是强账号系统。

## 三、信息架构

```
群主电脑（Electron）
├── 邀请页（无消息/无成员时）      二维码 + 群名 + 「手机或电脑扫码加入」
├── 群聊页
│   ├── 顶栏：群名、在线人数、成员头像堆叠、邀请、搜索
│   ├── 消息流：作者头像/昵称、@高亮、系统消息、日期分隔
│   ├── 输入区：文字、表情、图片、文件、@成员、引用
│   └── 成员侧栏（宽屏常驻 / 小窗抽屉）
│       ├── 群名片 + 邀请二维码
│       ├── 在线成员 / 离线成员
│       └── 移出成员 / 恢复成员
└── 设置：群名、我的昵称、锁定群聊、邀请链接、清空记录、原有传输设置

成员网页（手机 / 电脑浏览器）
├── 入群页：群名、在线人数、昵称、头像色、加入
├── 聊天页（手机单栏 / 电脑双栏）
│   ├── 顶栏：群名、在线人数、头像堆叠、邀请、搜索、更多
│   ├── 消息流 + 输入区（同群主）
│   └── 群信息侧栏/抽屉：二维码、成员、修改昵称、退出群聊
└── 设置：主题、字号、回车发送、震动、邀请、退出、帮助
```

## 四、数据模型

### 4.1 房间 `room.json`（群主本地）

```json
{
  "v": 1,
  "name": "近传群聊",
  "createdAt": 1760000000000,
  "locked": false,
  "host": {
    "id": "host",
    "name": "我的电脑",
    "color": "sky",
    "kind": "desktop",
    "joinedAt": 1760000000000
  },
  "members": {
    "a1b2c3d4e5f6": {
      "id": "a1b2c3d4e5f6",
      "name": "李雷",
      "color": "mint",
      "kind": "phone",
      "joinedAt": 1760000001000,
      "lastSeen": 1760000009000,
      "keyHash": "sha256…"
    }
  },
  "blocked": [
    { "id": "…", "name": "…", "at": 1760000000000 }
  ]
}
```

- 昵称：去控制字符、去空白、最多 16 个字符；重名自动加 `·2`。
- 头像：8 色固定调色板 `sky / mint / amber / rose / violet / lime / coral / slate`，客户端只拿 id。
- 成员 key：服务端生成，客户端保存在 `localStorage`；服务端只存 SHA-256，不落明文。
- 在线状态不落盘：由当前 WebSocket 连接推导，群主永远在线。

### 4.2 消息

在现有消息字段上追加：

```js
{
  id, ts, status, kind, text/name/size/mime/path, reply,
  uid: "a1b2c3d4e5f6",                 // 作者 member id；群主为 "host"
  author: { id, name, color, kind },   // 发送时快照，成员被移出后仍能显示
  mentions: ["host", "…"],             // 文本中 @ 到的成员
  seenBy: ["host", "…"],               // 已读成员，作者除外
  from: "pc" | "phone" | "system",     // 兼容旧客户端/Android 后台通知
  kind: "text" | "image" | "file" | "system",
  sys: { event, actor, target }        // 仅系统消息
}
```

- 旧消息没有 `uid/author`：`from=pc` 归群主，`from=phone` 显示为「成员（历史）」。
- 群系统消息：加入、改名、移出、群名变更、锁定；居中灰字，不进未读、不弹通知。
- 已读：客户端批量上报，服务端去重写入 `seenBy`；作者自己不算。群主桌面显示双勾 + 悬浮人数，网页显示「已读 N」。

## 五、协议

### 5.1 HTTP

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/history` | 兼容旧客户端；返回消息 + 群信息 |
| GET | `/api/room` | 群预览 + 邀请 URL/二维码（需令牌） |
| POST | `/api/send/text` | 文字；带成员头按成员署名，无头仅旧 Android 原生 UA 走兼容 |
| POST | `/api/upload/init` | 上传；同样支持成员署名 |
| POST | `/api/msg/:id/recall` | 撤回自己的消息，2 分钟内 |
| DELETE | `/api/msg/:id` | 删除自己的消息（群主 IPC 可删任意） |
| POST | `/api/clear` | 仅群主（实际由桌面 IPC 调用）；网页端不再提供 |

成员鉴权头：

```
x-ns-member: <memberId>
x-ns-key: <memberKey>
```

- 有头但无效 → 401，不降级；
- 无头且 UA 是旧版 Android 原生（`LanDrop-Android/1.0` / `NearSend-Android/1.0`）→ 兼容身份（`uid: "legacy"`），保证原生分享/通知回复仍可用；
- 无头且 UA 是浏览器 → 401，不能借共享令牌匿名冒充成员。

### 5.2 WebSocket

连接：`/ws?t=<token>`

| 方向 | 帧 | 说明 |
|---|---|---|
| S→C | `{t:"ready", room, members}` | 连接建立，等待 hello |
| C→S | `{t:"hello", member:{id?,key?,name,color,kind}}` | 首次无 id/key，服务端创建并下发 |
| S→C | `{t:"welcome", me, room, members, messages, url}` | 入群成功 |
| S→C | `{t:"denied", code, message}` | `identity / blocked / locked / full` |
| S→C | `{t:"room", room, members}` | 成员/在线/群名/锁定变化 |
| C→S | `{t:"text", text, cid, reply}` | 发文字 |
| S→C | `{t:"msg", msg}` / `{t:"ack", cid, id, msg}` | 广播 / 回执 |
| S→C | `{t:"msg:update", id, patch}` | 已读、上传进度等 |
| S→C | `{t:"msg:delete", id}` | 删除 |
| C→S | `{t:"seen", ids}` | 已读回执 |
| C→S / S→C | `{t:"typing", on}` / `{t:"typing", id, name, on}` | 输入状态 |
| C→S | `{t:"delete", id}` / `{t:"recall", id}` | 仅自己的消息 |
| C→S | `{t:"leave"}` | 退出群聊 |
| S→C | `{t:"kicked"}` | 被移出 |
| C→S/S→C | `{t:"ping"}` / `{t:"pong"}` | 心跳 |

兼容：旧 Android 后台 `LinkService` 只认 `msg` 且 `from=pc`，新协议保持群主消息 `from=pc`，因此通知继续工作；旧客户端不发 hello，只作为只读观察者，不进入成员列表。

## 六、关键交互

### 入群

1. 扫码/打开链接 → 拉 `/api/room` 显示群名、在线人数、头像堆叠。
2. 填昵称（按设备预填）+ 选头像色 → 加入。
3. 首次加入服务端生成 id/key；客户端 `localStorage` 保存，之后重连自动恢复。
4. 群被锁定：新成员看到「群聊已锁定」；已有身份仍可进入。
5. 被移出：提示「你已被移出群聊」，可清空身份以新成员重新加入（群主可恢复旧成员）。

### 群聊

- 非本人消息：头像 + 昵称 + 气泡；同一作者 3 分钟内连续消息合并（隐藏重复头像/昵称）。
- 本人消息：右对齐，不显示头像。
- 系统消息：居中胶囊，弱化处理。
- @：输入 `@` 弹出成员选择；消息内 `@昵称` 高亮；被 @ 时通知前缀「有人@你」。
- 已读：网页「已读 N」；桌面双勾并在 title 里显示人数。
- 输入状态：聚合显示「张三、李四 正在输入…」，超过 3 人显示「3 人正在输入…」。
- 引用：引用块显示作者名；点击跳回原消息。
- 文件：群内共享，任何成员可按需下载；上传进度对所有人可见。
- 桌面网页：宽屏双栏、右键消息菜单、拖拽上传、粘贴图片、Enter 发送默认开启。
- 手机网页：长按菜单、底部弹层、震动、相册/文件保存、原生桥不变。

### 群主控制

- 成员侧栏点击成员 → 移出；已移出列表可恢复。
- 群名、我的昵称：设置页内联弹窗修改。
- 锁定群聊：开关；不影响已入群成员。
- 重置邀请：复用现有令牌重置，所有设备需重新扫码，但成员身份和群历史保留。

## 七、边界与异常

| 场景 | 处理 |
|---|---|
| 群主电脑休眠/退出 | 所有成员显示「连接断开，正在重连」；文件与消息在群主恢复后可用 |
| 成员锁屏/切网 | ping/pong + 15s 心跳；断线进待发送队列，恢复后补发 |
| 同一成员开两个标签页 | 同一 member id，在线状态合并；消息按 cid 去重 |
| 昵称重复 | 服务端自动加 `·2`，并在入群回执里返回最终昵称 |
| 群主重置令牌 | 成员身份保留；旧链接失效，需要重新扫码 |
| 群主清空记录 | 消息清空，成员与群设置保留，已保存文件保留 |
| 旧版记录 | 按 from 兼容显示，不追溯署名 |
| 旧 Android 后台通知 | 仍只对群主消息通知；群成员消息需打开网页查看 |
| 上传一半成员离线 | 现有上传会话 5 分钟清理；重连后可重新发送 |
| 成员被移出后仍持有文件直链 | 令牌仍有效时可下载；这是局域网弱边界，安全说明中写明 |

## 九、明确不做（本期）

- 多群/房间列表、私聊、好友体系
- 语音/视频通话、屏幕共享
- 表情回应、投票、置顶、群公告
- 端到端加密（消息仍在群主电脑上加密落盘）
- 真正的账号级封禁（移出基于 member id；清空浏览器身份可重新入群）
