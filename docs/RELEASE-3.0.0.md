# 近传 3.0.0 · 远程工位（内部内测）

发布日期：2026-11-17

首个把“设备控制 + 局域网远控 + 团队群聊 + 同事私聊”放在一个 Windows 工作台里的内测版本。

## 新增

- 统一工作台：设备、会话、消息、授权、审计、诊断、设置。
- 设备历史：记住已发现的工位，关机/睡眠后以离线状态保留；不做远程唤醒。
- 局域网设备发现；广播被禁用时可手动输入 `IP:端口`；6 位码首次配对；控制端身份记住。
- 真实屏幕帧与 Windows 键鼠注入；支持点击、拖动、滚轮、常用快捷键。
- 本机被控：授权码、IP/端口、当前会话、已授权控制端、暂停/恢复、撤销授权、结束会话。
- 会话工具条：屏幕切换、画质、剪贴板、文件、录制、Ctrl+Alt+Del。
- 管理员临时支持：添加设备时选择角色；默认 8 小时，无人值守/剪贴板/文件/录制关闭，工位端可撤销。
- 文件双向：控制端发送到被控端 `下载/NearSend`；被控端会话中可发送文件给控制端。
- 本地录制：控制端在会话内录制 WebM；默认关闭，工位端显示录制状态。
- 团队群聊保留 2.2.0 全部功能；同事私聊按设备 1:1 UDP 直连。
- 真实诊断、本机审计（持久化到本机）、授权页（本机授权控制端/当前获得授权/撤销）、主题切换、开机启动联动。
- 新版介绍页 `site/index.html`、发布页 `site/release.html`。

## 已知限制

- 仅同一 Wi-Fi/VLAN，不支持公网穿透。
- 屏幕采集为 Windows GDI + 局域网 WS + JPEG（1080p 约 15fps、2K 约 10–12fps）；WebRTC/2K60 后续替换。
- 锁屏/UAC 安全桌面需要 Windows 服务，当前只覆盖已登录桌面。
- 文件支持控制端 → 被控端，以及被控端会话中“发送文件给控制端”；完整远程文件浏览器未开放。
- 管理员临时授权已按 8 小时限制并关闭受限权限；完整的组织级授权与审批流仍在内测中。
- 录制默认关闭；当前为控制端本地 WebM 录制，未接入保留策略/员工拒绝流程。
- 控制通道为内网 WS，未启用跨网 TLS；只允许在受控办公 VLAN 内使用。

## 安装

- `NearSend-3.0.0-Setup.exe`（NSIS，x64）
- `NearSend-3.0.0-Portable.exe`（便携版）
- Windows 10/11 x64；输入注入组件随包分发。

- 群聊窗口与工作台入口通过。
