# 从旧版本升级到 2.0.0

这份文档解释三件用户最常问的事：为什么电脑上有两个版本、为什么安装包会说「降级」、以及怎么一次清干净。

---

## 一、为什么电脑上会出现两个版本

Windows 判断「是不是同一个软件」看的是**应用标识（appId）**，不是显示名称。

| 版本 | 显示名称 | appId | 安装目录 |
| --- | --- | --- | --- |
| v1.1.0 及更早 | LanDrop / 局域网传信 | `com.landrop.app` | `%LOCALAPPDATA%\Programs\LanDrop` |
| v1.0.0 – v1.0.2 | 近传 NearSend | `com.nearsend.app` | `%LOCALAPPDATA%\Programs\NearSend` |

两套标识互不相干，所以装完 1.0.x 之后，1.1.0 依然在，两个都会出现在「应用和功能」里，
各自有一个托盘图标、各自占用一个端口（8899 / 8900…），手机也可能连到不同的那一个。

**2.0.0 的处理**：安装包启动时扫描 LanDrop 的安装目录，先请它退出，再静默卸载，然后安装近传。

---

## 二、为什么新安装包会提示「是否降级」

旧安装脚本用 NSIS 的 `VersionCompare` 判断版本高低，但把返回值用反了：

- `VersionCompare` 返回 **1** 表示「第一个版本更高」，返回 **2** 表示「第一个版本更低」
- 脚本却把 1 当成「安装包更新」、2 当成「安装包更旧」

结果就是：已安装 1.0.2、安装包也是/更高时，反而弹出「当前已安装 X，高于此安装包 Y，是否降级」。

**2.0.0 的处理**：

| 情况 | 行为 |
| --- | --- |
| 已安装版本更旧 | 直接覆盖升级，不弹窗 |
| 版本相同 | 视为修复安装，不弹窗 |
| 安装包确实更旧 | 提示「装回旧版」，可取消 |

加上版本号提升到 2.0.0（高于 1.1.0），从任何历史版本升级都不会再被判定为降级。

---

## 三、升级步骤（推荐）

1. **不需要手动关闭**：安装包会自动结束正在运行的近传 / LanDrop（托盘常驻也不影响）
2. 双击 `NearSend-2.0.0-Setup.exe`
3. 如果提示检测到旧版本 LanDrop，选「确定」，安装程序会先卸载它
4. 选择「仅为当前用户安装」和安装位置（默认即可），下一步
5. 在「开机启动」页决定是否随 Windows 启动（默认勾选），下一步
6. 完成后程序自动启动，托盘出现图标，窗口里是一张新的二维码

聊天记录不需要手动搬：程序启动时会把 `%APPDATA%\LanDrop` 里的
`messages.jsonl`、`messages.key`、`Local State`、`config.json` 迁移到 `%APPDATA%\NearSend`。

---

## 四、手工清理（安装包没能清掉时）

1. 「设置 → 应用 → 已安装的应用」里卸载名字含 LanDrop / 局域网传信 的条目
2. 确认只剩「近传 NearSend」一项，版本 2.0.0
3. 可选删除旧目录：`%LOCALAPPDATA%\Programs\LanDrop`
4. `%APPDATA%\LanDrop` 建议先保留：迁移完成、确认聊天记录都在之后再删

---

## 五、升级后怎么验证

| 检查项 | 期望 |
| --- | --- |
| 「应用和功能」列表 | 只有一条「近传 NearSend」 |
| 托盘图标 | 只有一个小箭头图标，没有第二个 |
| 设置 → 关于 | 版本号 2.0.0 |
| 手机聊天页 | 发消息后气泡立即从「发送中」变成时间 + 单勾，不再停在「待发送」 |
| 电脑收到消息 | 托盘气泡或窗口立即出现新消息 |

---

## 六、如果手机还是显示「待发送」

2.0.0 已经给发送加了回执、超时重发和心跳。如果仍然出现：

1. 在手机上把聊天页下拉刷新（或退出重进），让页面重新连接
2. 点一下那条「未送达」的气泡，会就地重发
3. 电脑端设置里确认「令牌」没有重置过；重置过就重新扫一次码
4. 手机与电脑要连同一个 Wi-Fi；公司网络开了「AP 隔离」时，两台设备互相不可见
5. Windows 防火墙放行：首次运行会提示，允许「专用网络」即可
