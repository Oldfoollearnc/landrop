# 近传远程工位 V1 · 架构与边界

内部内测版，仅 Windows 10/11 x64，仅同一 Wi-Fi/VLAN。

## 组件

| 组件 | 位置 | 说明 |
|---|---|---|
| 统一工作台 | `src/renderer/workspace/` | 设备、会话、消息、授权、审计、诊断、设置 |
| 团队群聊 | `src/renderer/desktop/` + `src/main/server.js` | 现有 2.2.0 单房间群聊，手机/浏览器扫码加入 |
| 远程管理器 | `src/main/remote.js` | UDP 发现、WS 会话、配对、权限、文件、录制状态 |
| 输入注入 | `assets/remote-input.exe` | C#，`SendInput`/`keybd_event`/`SetCursorPos` |
| 屏幕采集 | `assets/remote-capture.exe` | C# GDI `CopyFromScreen` + JPEG，输出 base64 帧 |
| 工作台 IPC | `src/preload/workspace.js` | contextBridge，无 nodeIntegration |

## 网络

- UDP `47822`：局域网设备发现/广播。
- UDP `47823`：同事私聊（按设备 1:1）。
- TCP `47820–47839`：远程控制 WebSocket 会话。
- 不使用云端、Hub、账号体系或组织目录。
- 设备发现不可跨网段；AP 客户端隔离会阻断发现与会话。广播被禁用时可在「添加设备」手动输入 `IP:端口`（默认 47820）。

## 配对与授权

1. 被控端生成 6 位授权码，显示在「本机被控」。
2. 控制端第一次连接时输入该码。
3. 被控端把控制端 ID 写入本机 `remote.json`，下次可直接连。
4. 控制端在添加设备时选择角色：
   - **我的设备**：长期、无人值守策略开、剪贴板/文件可用、录制可用（默认不录制）。
   - **管理员临时支持**：8 小时、无人值守/剪贴板/文件/录制关闭、只读审计。
5. 被控端「本机被控 → 已授权控制端」可查看角色/到期并撤销；撤销立即断开。

> 内测版以 6 位码作为首次信任凭证。角色由控制端声明，被控端显示并允许撤销；完整工位端审批流不在本版范围。

## 屏幕与输入

- 采集：GDI BitBlt（`CopyFromScreen`）→ 等比缩放 → JPEG → base64。
- 目标帧率：1080p 约 15fps、2K 约 12fps、720p 约 20fps；弱网/高负载会下降。
- 控制端 canvas 等比显示，指针坐标按实际画面矩形归一化。
- 被控端按 `screen.dipToScreenPoint` 转成物理像素后注入，兼容高 DPI。
- 双屏一次只传一块，按显示器切换；不并发传两块屏。
- 输入覆盖已登录桌面；锁屏/UAC 安全桌面需要原生 Windows 服务，当前不支持。

## 文件 / 剪贴板 / 录制

- 文件分块走同一 WS；控制端 → 被控端写入 `下载/NearSend`。
- 被控端会话中可「发送文件给控制端」，接收端写入自己的 `下载/NearSend`。
- 剪贴板双向：控制端按钮发送；被控端变化每 1.2s 推送到控制端。
- 录制由控制端在本地用 `MediaRecorder` 录 WebM，默认关闭；保存位置由系统保存对话框决定。
- 录制状态同步到被控端，工位端显示「录制中」。

## 本机数据

- `remote.json`：设备 ID、控制端 ID、授权列表、已发现设备。
- `remote-audit.json`：本机审计（配对、会话、私聊、文件、授权）。
- 会话历史：工作台 `localStorage`。
- 群聊记录：现有群聊存储（加密），仅在群主电脑。

## 明确不做

- 公网穿透、跨网段、Wake-on-LAN、关机/睡眠唤醒。
- 4K/120fps、4:4:4、多人同时控制同一台电脑。
- 组织级集中管理、集中审计、20 路监控墙。
- 手机作为控制端；手机仍只加入团队群聊。
