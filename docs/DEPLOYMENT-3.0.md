# 近传 3.0 · 内部部署与回滚

适用：Windows 10/11 x64，办公 Wi-Fi/VLAN，内部自用。

## 1. 安装

1. 从发布页或内部 IT 获取 `NearSend-3.0.0-Setup.exe`。
2. 在需要被控的工位电脑和控制端电脑分别安装；安装时保留默认安装目录。
3. 首次启动如出现 Windows 防火墙提示，允许“专用网络”。
4. 确认托盘出现近传图标；工作台打开到“设备”页。

便携版 `NearSend-3.0.0-Portable.exe` 适合临时测试，不建议作为长期工位端。

## 2. 网络与防火墙

| 方向 | 端口/协议 | 用途 |
|---|---|---|
| UDP | 47822 | 局域网设备发现/广播 |
| UDP | 47823 | 同事私聊 |
| TCP | 47820–47839 | 远程控制 WebSocket |

- 两台电脑必须在同一网段/同一 Wi-Fi/VLAN。
- 如交换机/AP 开启“客户端隔离/AP 隔离”，发现和直连都会失败；需要 IT 关闭。
- 广播被禁用但单播可达时，在控制端「添加设备」手动输入工位 IP:47820。
- 不需要公网、端口映射或 VPN；不要把 47820–47839 暴露到公网。

## 3. 首次配对与角色

1. 工位电脑：工作台右上角“本机被控”，确认已开启，记下 6 位码。
2. 控制端：设备 → 添加设备 → 选择发现的设备（或手动 IP）。
3. 连接身份：
   - **我的设备**：本人长期使用，剪贴板/文件可用，录制默认关闭。
   - **管理员临时支持**：8 小时到期，无人值守/剪贴板/文件/录制关闭；工位端可随时撤销。
4. 输入 6 位码完成首次配对；之后控制端会记住，重连不再要求输入。
5. 工位端“已授权控制端”可查看角色/到期并撤销；撤销后当前会话立即断开。

## 4. 日常使用

- 会话工具栏：屏幕切换、画质、剪贴板、文件、录制、更多。
- HUD：RTT、实时帧率、采集方式（GDI）、画质。
- 文件：控制端 → 工位端 `下载/NearSend`；工位端也可发送给控制端；重名自动加序号。
- 录制：控制端本地 WebM，默认关闭；工位端显示“录制中”。
- 团队群聊：工作台“消息 → 打开团队群聊”；手机/浏览器扫码加入，协议兼容 2.2.0。
- 同事私聊：消息页选择发现的同事，1:1 UDP 直连，不上云。

## 5. 数据与审计

| 数据 | 位置 | 说明 |
|---|---|---|
| 设备/授权/发现历史 | `%APPDATA%\NearSend\remote.json` | 本机；不含 Windows 密码 |
| 本机审计 | `%APPDATA%\NearSend\remote-audit.json` | 配对/会话/私聊/文件/授权，最多 500 条 |
| 会话历史 | 工作台 localStorage | 本机 |
| 群聊记录 | 群主电脑的现有加密存储 | 手机端不保存完整历史 |
| 录制 | 保存对话框选择的位置 | 仅控制端本地 |

“设置 → 诊断与支持 → 本机数据目录”可直接打开数据目录。

## 6. 升级

1. 尽量在无活动会话时升级。
2. 运行新安装包覆盖安装；安装器会保留用户数据。
3. 启动后确认版本号 3.0.0，打开一次本机被控，确认授权码与已授权控制端仍在。
4. 如控制端提示授权失效，重新输入工位端 6 位码即可。

## 7. 回滚

1. 结束所有远程会话。
2. 卸载当前版本（保留应用数据）。
3. 安装上一版内测包。
4. 如授权数据不兼容，在工位端撤销旧控制端并重新配对；群聊记录不受影响。

## 8. 已知限制

- 仅覆盖已登录 Windows 桌面；锁屏/UAC 安全桌面需要原生服务，当前不支持。
- 采集为 GDI + JPEG：1080p 约 15fps、2K 约 10–12fps、720p 约 20fps；不是 2K60/WebRTC。
- 不做公网穿透、跨网段、WoL、关机/睡眠唤醒。
- 不提供组织级集中授权/集中审计/20 路监控墙；授权与审计分布在各工位电脑。
- 录制为控制端本地行为，尚未接入企业保留策略或员工拒绝流程。
- 控制通道为内网 WS，未启用跨网 TLS；只允许在受控办公 VLAN 内使用。

## 9. 排障

**发现不到设备**
- 确认双方都打开近传、被控已开启。
- 检查同一网段、AP 隔离、Windows 防火墙专用网络。
- 试用手动 IP:47820；仍失败则在工位端运行“诊断”并导出诊断包。

**能发现但连接失败**
- 确认 6 位码正确/未刷新。
- 确认 TCP 47820 可达；检查安全软件拦截。
- 若工位端撤销过授权，重新配对。

**画面卡顿**
- 切 1080p 或 720p；优先 5GHz/有线；关闭占用带宽的下载。
- 运行诊断，检查 AP 隔离/丢包。

**文件没有出现**
- 检查工位端 `下载/NearSend`；重名文件会带 `(1)`。
- 检查会话授权是否包含“文件”。

**锁屏后无法操作**
- 当前版本不支持安全桌面，这是已知限制；需要在工位端解锁后再连接。
