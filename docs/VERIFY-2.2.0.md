# 近传 2.2.0 · 群聊验证记录

日期：2026-11-16

## 自动化

### `npm test`（服务端协议）

全部通过，新增覆盖：

- `GET /api/room` 返回群名、在线人数、邀请 URL 与二维码
- WebSocket `hello → welcome`，首次入群下发 member key
- 成员列表包含新成员且在线
- 成员改名后 `me` 帧与 roster 同步
- 已读回执写入 `seenBy`
- 移出成员后进入黑名单，原 key 不能直接回来
- 恢复成员后原 key 可以重新入群
- 旧版 Android 原生 UA 的令牌-only 请求仍能发文字/上传
- 浏览器 UA 无成员身份时发文字返回 401（不能借共享令牌匿名冒名）
- `/api/clear` 远程调用返回 403，只有群主桌面端能清空

### 真实 Chromium 端到端（Playwright）

- 扫码页 → 入群页：群名、在线人数、昵称、头像色
- 入群后显示历史消息、成员侧栏、在线人数
- 发送文字 → `ack` 回执 → 本地气泡替换为正式消息
- `@李` 触发成员选择器；选择后插入 `@李雷 `；发送后蓝底高亮
- 引用回复：消息内显示作者和原文
- 群成员抽屉：在线/离线、群主/我标记、邀请二维码、修改昵称、退出
- 网页上传真实文件：`/api/upload/init` → 分片 PUT → `/done`，消息 `status=ok`，
  作者为当前 member，文件落盘到群主保存目录
- 修改昵称：系统消息「X 改名为 Y」，成员列表同步
- 深浅主题：入群页、消息、@ 选择器、成员抽屉均正常

## 已知边界

- 旧版 Android 后台通知只接收群主消息；其他成员消息需打开聊天页查看。
- 旧版 Android 的「清空电脑端聊天记录」在 2.2.0 会收到 403；清空改为群主电脑独占。
- 移出基于 member id；清空浏览器 localStorage 后可以以新身份重新入群（局域网弱身份模型）。
- 文件直链仍由令牌保护；成员 key 只用于防止消息冒名，不做账号级权限。
